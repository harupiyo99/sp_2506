# プロジェクト概要

## 🎯 プロジェクトの目的

このプロジェクトは、OPRF（Oblivious Pseudorandom Function）プロトコルを活用したセキュアなデータ処理システムを提供します。フロントエンドとバックエンドの両方を含む完全なWebアプリケーションとして構成されています。

## 🏗️ システム構成

### アーキテクチャ概要

```
┌─────────────────┐    HTTP/HTTPS    ┌─────────────────┐
│   Frontend      │◄─────────────────►│   Backend       │
│   (React)       │                   │   (Express)     │
│                 │                   │                 │
│ • UI Components │                   │ • OPRF Service  │
│ • API Client    │                   │ • REST API      │
│ • State Mgmt    │                   │ • Auth System  │
└─────────────────┘                   └─────────────────┘
```

### 主要コンポーネント

#### フロントエンド (`jph-front-core`)
- **技術スタック**: React + TypeScript + Vite
- **主要機能**:
  - ユーザーインターフェース
  - API通信クライアント
  - データ入力・表示フォーム
  - リアルタイム結果表示

#### バックエンド (`jph-back-core`)
- **技術スタック**: Bun + TypeScript + Express.js
- **主要機能**:
  - OPRFプロトコル実装
  - RESTful API提供
  - セキュアなデータ処理
  - Swagger API ドキュメント

## 🔐 セキュリティ機能

### OPRFプロトコル
- **目的**: データのプライバシーを保護しながら計算を実行
- **特徴**:
  - サーバーは入力データを直接見ることができない
  - クライアントは計算結果のみを取得
  - 中間者攻撃に対する耐性

### セキュリティ対策
- 秘密鍵の安全な管理
- HTTPS通信の強制
- 入力データの検証
- エラーハンドリングによる情報漏洩防止
